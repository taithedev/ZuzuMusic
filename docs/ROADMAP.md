# ZuzuMusic roadmap

## Phase 1: Alpha (this repository)
- [x] Modern responsive player with local file imports
- [x] Playback controls, queue, likes and local playlists
- [x] Audio speed and bass/treble filters
- [x] Username/password accounts, Neon SQL schema
- [x] Signed private R2 uploads, pending review and approved release streaming
- [x] Administrator review queue
- [x] External Spotify search/open links
- [ ] Test against a configured real Neon and R2 environment

## Phase 2: Public beta prerequisites
- [ ] Strong rate limits and anti-bot protections
- [ ] Account recovery, deletion/export and guardian policies
- [ ] Reporting, copyright takedown, moderation audit trails and appeals
- [ ] Audio malware scanning, storage cleanup, safe upload checks
- [ ] Creator cover art and artist profiles
- [ ] Sync playlists, likes and settings across devices
- [ ] Original audio waveforms and creator-owned synchronized lyrics
- [ ] Security, browser and accessibility tests

## Phase 3: Native apps and discovery
- [ ] Tauri Windows app and installer with desktop media controls
- [ ] Cross-platform desktop/mobile apps
- [ ] Artist following and release notifications
- [ ] Creator analytics and opt-in ZuzuMusic recommendations
- [ ] Clear rights and payment arrangements before any monetization

ZuzuMusic will not download Spotify streams, bypass Premium, combine audio services, or claim catalog rights it does not have.
